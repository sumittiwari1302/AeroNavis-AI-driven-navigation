## 2. What We DO NOT Claim

| Category | Explicit Non-Claim | Rationale |
|----------|-------------------|-----------|
| **Long-term drift-free** | No guarantee of <1 m after 10 min without GNSS | Pure INS physics: cubic position error growth |
| **RTK-grade** | Not centimeter-level; no carrier-phase | Phone GNSS is code-phase only |
| **Pedestrian indoor (no map)** | Shop-around / mall navigation without floorplan | No Wi-Fi/BLE fingerprinting; IMU-only pedestrian PDR not implemented |
| **Aggressive off-road** | Jumps, drops, >30° slopes, mud/snow slip | Slip classifier trained on paved roads (IO-VNBD) |
| **Underwater / tunnel > 5 min** | Beyond forecaster horizon (max 15 s) | Covariance inflation has limits; map matching needs road graph |
| **Multi-floor building** | Vertical (z) accuracy not guaranteed | Barometer + IMU z has >5 m drift in 60 s |
| **Pedestrian pocket/bag** | No dedicated pedestrian mode (step detection) | Models trained on vehicle dynamics (4-wheeler + 2-wheeler) |
| **Adversarial GNSS spoofing** | Can detect gross jumps (>5 m) but not sophisticated spoofing | Uses residual gating + map consistency, not crypto auth |

| Aspect | Detail |
|--------|--------|
| **Primary training data** | IO-VNBD (UK/France/NG), RONIN (indoor), IDOL (indoor), Self-collected (India) |

## 4. Confidence Reporting Contract (UI Must Implement)

| Trust Level | Condition | UI Display |
|-------------|-----------|------------|
| **HIGH** | ATE ≤ 1 m, drift ≤ 5%/km, cov < 10 m², GNSS healthy | 🟢 "HIGH — Sub-meter" |
| **MEDIUM** | ATE 1–3 m, drift 5–15%/km, cov 10–100 m², or short blackout < 60 s | 🟡 "MEDIUM — ~2 m" |
| **LOW** | ATE > 3 m, drift > 15%/km, cov > 100 m², no GNSS ever, spoof detected | 🔴 "LOW — Position uncertain" |

**Rule**: Never silently inflate accuracy. If filter covariance grows > 100 m² without re-anchor, force LOW.

## 5. Failure Modes (Honest Disclosure)

| Failure Mode | Detection | Fallback |
|--------------|-----------|----------|
| **Velocity model OOD** | Attitude canonicalization residual > threshold | Fallback to NHC-only (InEKF) |
| **Pseudo-odo slip undetected** | Slip classifier confidence < 0.5 | Down-weight wheel (R×10) |
| **VO texture gate false positive** | Reprojection error > 2 px | Disable VO, flag MEDIUM |
| **Forecaster false negative** | GNSS drops without prediction | Seeder catches in < 1 s, inflates cov |
| **Map match wrong road** | Viterbi path prob < 0.3 | Ignore map, rely on InEKF |
| **LoRA divergence** | Adapter norm > 2× init | Reset to base weights |
